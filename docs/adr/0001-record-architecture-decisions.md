# 1. Record architecture decisions

- Status: accepted

## Context

Agents and people work on this project in separate sessions; decisions must survive between them.

## Decision

Every significant technical decision gets a short record in `docs/adr/NNNN-title.md` (context, decision,
consequences). Product decisions belong to the owner and are recorded in `docs/answers.md`.

## Consequences

A new session reads the ADRs instead of rediscovering past choices.
