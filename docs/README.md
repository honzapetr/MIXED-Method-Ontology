# Docs

Documentation of the environment. Nothing about a concrete study belongs here – studies live in `topics/<slug>/`,
methods in `methods/` (`development.md`).

## How we build the environment (project memory)

| File | Content |
| :--- | :--- |
| `development.md` | the working rules while building: two lines, what goes where |
| `brief.md` | what the owner wants: goal, scope, non-goals |
| `spec.md` | how the environment will work: behaviour, data, interfaces |
| `plan.md` | tasks `T<n>` with acceptance criteria and verify commands |
| `answers.md` | the owner's answers and decisions, newest last |
| `progress.md` | a short entry after every task |
| `adr/` | one file per significant decision |
| `owner-notes.md` | the owner's own notes while building |
| `source-pipeline.md` | how every kind of source becomes `text.md`, segments and quotations: steps, formats, built and planned |

## How the environment works (manual)

| File | Content | Status |
