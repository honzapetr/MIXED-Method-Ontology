# SKAD – connected applications

> Applications a SKAD analysis can work with, and what passes between them and the project. Status: none is
> connected yet; the list grows as the first study shows what is needed (owner, 2026-11-14).

| Application | Use in SKAD | Exchange | Status |
| :--- | :--- | :--- | :--- |
| ATLAS.ti | the owner's known QDA tool: reading, coding, network views of schemes and positions | REFI-QDA project (`.qdpx`): sources, segments, codes, memos | planned |
| QualCoder | open-source QDA tool, same use | REFI-QDA project (`.qdpx`) | planned |

What maps to a QDA project:
- sources and their segments – documents and quotations;
- SKAD code types (interpretive scheme, classification, phenomenon dimension, narrative element, speaker and
  subject position, practice) – code groups, one per type;
- relations – links between codes (network view);
- memos – memos, with their type in the name or a group.

Open: whether codes made in a QDA tool come back into the project (round trip), and how their status and author
are kept.
